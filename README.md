## 这是什么

## 手机复习方法（建议三遍法）

1. **通读**（今天，~1.5 小时）：01 → 03 → 09，建立整体框架；
2. **做题**（明天，~2 小时）：04、05、06 逐题自测——先盖住答句回忆再说出来；
3. **速记**（面试当天，10 分钟）：只看 [11-考前速记卡](11-考前速记卡.md) + 五张故事卡口述一遍（[10-STAR故事卡](10-STAR故事与面试技巧.md)）。
